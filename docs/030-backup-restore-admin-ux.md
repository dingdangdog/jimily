# 030 — 数据库恢复：管理员覆盖说明与恢复后自动登出

## 变更时间

2026-03-30

## 摘要

- 在管理端「数据备份与恢复」中补充**新部署 → 先初始化再恢复**场景的说明（浅色提示条），明确恢复后**当前管理员会被备份中的用户表覆盖**。
- 「从 JSON 恢复」确认弹窗改为分条说明：数据清空范围、**管理员信息将会被覆盖**、恢复后自动退出登录等；确认按钮文案为「我已了解，仍要恢复」。
- 数据库恢复**成功后**：提示成功 → 短暂延迟后调用 `api/logout`（失败则本地清空 `Authorization` / `Admin` Cookie）、`useUserStore().clearUser()`，并以 `replace` 跳转 `/login`。
