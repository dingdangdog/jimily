# 024 — 表单类弹窗禁止点击蒙层关闭

## 背景

点击半透明蒙层空白区域会关闭弹窗，容易在填写表单或导入数据时误触关闭，打断编辑流程。

## 改动

对以下场景的**最外层蒙层**移除 `@click` / `@click.self` 关闭逻辑，仅保留标题栏/底部「取消」等显式关闭入口；内层面板仍使用 `@click.stop`，避免事件冒泡。

- 用户：资金账户编辑、类型编辑、流水页 CSV/自定义导入与批量改类型、日历页 CSV/自定义导入、Jimi 页 CSV 导入、API 令牌测试弹窗。
- 管理端：用户编辑、管理员改密弹窗、类型关联编辑弹窗。
- 组件：`FlowCustomImport` 全屏导入蒙层、Jimi 助手居中弹窗、`FlowEditInvoiceDialog` 内删除发票确认蒙层（须通过按钮取消/确认）。

未改动的蒙层行为：只读类弹窗（如月度分析、流水列表大图）、侧滑筛选/搜索抽屉、移动端会话抽屉等仍可按原交互点击外侧关闭。
