# 014 — OpenAPI 文档侧栏分组顺序

## 排序机制说明

- **分组（Tag）顺序**：OpenAPI 顶层字段 **`tags`** 为对象数组时，Scalar、Swagger UI 等通常按该数组顺序渲染侧栏分组，而不是按字母或首次出现顺序。
- **分组内接口顺序**：一般由各工具自行决定（常见为路径或方法排序）；本项目未做逐接口 `x-order` 定制。

## 本次调整

在 `swagger.config.ts` 的 `swaggerDefinition` 中增加有序 **`tags`** 列表，并附简短 `description`，便于读者理解每一类的职责。

顺序设计思路：**先账号与集成（基础 → 用户 → 管理后台 → AI 接口（v1））**，再**核心业务数据（流水 → 流水分类/固定流水 → 预算/应收/发票）**，接着**分析与映射**，最后**导入辅助（导入候选、去重）**，**测试**置底。（侧栏展示为中文 tag 名，见 `016-openapi-tags-chinese.md`。）

## 验证

启动应用后打开 `/api-docs`，确认侧栏分组顺序与 `swagger.config.ts` 中 `tags` 数组一致。
